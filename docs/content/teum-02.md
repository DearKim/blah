## 정체성 — 매칭 + 정보

TEUM은 단순한 긱워크 매칭 서비스가 아니라, **짧은 시간을 일과 수입으로 잇는 매칭** + **국가가 제공하는 공공 고용·노동 정보 안내** 두 가지를 한곳에서 제공하는 정보 서비스입니다. 후자는 BLAH 의 "정보" 미션과 직접 정렬되는 갈래입니다.

## 한 줄 정의 (`summary`)

> 짧지만 비어 있던 시간을 일과 수입으로 연결하고, 국가가 구직자·구인 사업체에 제공하는 공공 고용 정보까지 한곳에서 안내하는 정보 플랫폼입니다.

## 상세 본문 (`description`)

> 10분, 30분, 4시간 이하의 초단기 일을 빠르게 매칭해, 점심시간·공강·오후 두세 시간 같은 짧은 시간을 양쪽이 만나는 단위로 만듭니다. 동시에 국가가 구직자와 구인 사업체에 제공하는 공공 고용·노동 정보를 한곳에 모아 안내해, 자투리 시간을 수입으로 바꾸는 데 필요한 정보를 함께 정리합니다.

## 왜 만들었는가 (문제 정의)

- 점심시간 1시간, 공강 30분, 오후 두세 시간 — **짧지만 비어 있는 시간**은 누구에게나 있습니다.
- 기존 구인·구직은 일 단위·주 단위 이상의 호흡으로 짜여 있어, **자투리 시간**을 사용할 수 있는 매칭이 거의 없습니다.
- 국가가 구직자·구인 사업체에 제공하는 **지원·교육·세제 정보**는 흩어져 있어 평범한 사용자가 활용하기 어렵습니다.

TEUM은 이 두 가지 — **시간의 틈새**를 양쪽이 만나는 단위로 만드는 매칭, 그리고 흩어진 **공공 고용 정보**의 한곳 안내 — 를 묶은 서비스입니다.

## 무엇을 제공하는가 (홈 섹션 — `pillars`)

홈 섹션에서는 세 단락 블록으로 표시됩니다.

### ▎시간 단위 긱워크 매칭

> 10분 · 30분 · 4시간 단위로 일거리를 분류해, 점심시간·공강·오후 두세 시간 같은 짧은 틈새를 양쪽이 만나는 단위로 만듭니다. 면접 없이 즉시 시작 가능한 형태에 집중합니다.

### ▎AI 기반 틈새 매칭

> 가용 시간과 위치를 입력하면 적합한 일 카테고리를 안내하고, 대화형 온보딩으로 프로필을 자동 정리합니다. 자투리 시간이 수입이 되기까지의 마찰을 줄입니다.

### ▎공공 고용·노동 정보 (NEW)

> 국가가 구직자와 구인 사업체에 제공하는 지원·교육·세제 등 공공 고용 정보를 한곳에 모아 안내합니다. 흩어진 정보를 광고나 추천 없이 사실 그대로 전합니다.

## 상세 페이지 기능 리스트 (`features`)

1. **시간 단위 일자리 분류** — 10분 / 30분 / 4시간 이하로 일을 분류해 한눈에 비교합니다.
2. **AI 틈새 상담** — 가용 시간·위치를 입력하면 적합한 일 카테고리를 안내합니다.
3. **대화형 온보딩** — 챗 형식으로 프로필을 받아 자동으로 이력을 정리합니다.
4. **즉시 매칭 지향** — 면접 없이 바로 시작 가능한 형태의 일에 집중합니다.
5. **공공 고용·노동 정보 안내** — 국가가 구직자·구인 사업체에 제공하는 지원·교육·세제 정보를 함께 안내합니다.

> 톤 노트: "추천합니다" → "안내합니다" 로 통일. 브랜드 약속(추천 아닌 사실)에 맞춤.

## 누구에게 도움이 되는가

- 점심시간 등 자투리 시간을 수입으로 만들고 싶은 **직장인**
- 공강 시간을 활용하려는 **학생**
- 오후 시간이 비는 **주부**
- 단발성·짧은 도움이 필요한 **구인자**
- 공공 고용·노동 정보가 필요한 **구직자·사업체** (NEW)

## 약속

- 게시되는 모든 일은 **법정 최저임금 이상** 입니다.
- 노동법·세무 관련 표기는 게시물에 명확히 드러냅니다.
- 매칭 알고리즘과 정렬 기준은 사이트에 공개합니다.
- 안내하는 **공공 고용 정보는 출처와 갱신일자를 함께 표시**합니다. (NEW — A.PAGO 의 데이터 출처 약속과 평행)
