## 1. 적용 법령

A.PAGO 가 다루는 영역(병의원 + 동물병원 + 의료 AI 제품 정보) 은 다음 법령의 광고/처리 규제를 동시에 받습니다.
blah 사이트가 A.PAGO 를 소개할 때도 같은 규제선이 그대로 적용됩니다.

| 법령 | 조항 | 카피 작성 시 핵심 |
|---|---|---|
| 의료법 | 제27조 | 환자 유인·알선 금지 — 특정 병원으로 사용자를 유도하는 표현 금지 |
| 의료법 | 제56조 | 의료광고 금지·제한 — 효능 단정·과장·비교 표현 금지 |
| 의료기기법 | 제24조 | 의료기기 광고 규제 — 효능·성능·정확도 단정 금지, 광고 시 사전심의 필수 |
| 수의사법 | 제32조 | 동물진료 광고 제한 — 동물병원·펫 AI 영역에 동일하게 적용 |
| 수의사법 시행규칙 | 제24조 | 동물병원 광고 가능·불가 표시사항 |
| 개인정보보호법 | 제15·22·23조 | 민감정보(건강정보) 별도 명시적 동의 |
| 위치정보법 | 제15·19조 | 위치정보 수집·이용 동의 |
| 표시광고공정화법 | — | "광고" 표시 의무, 제휴/비제휴 시각적 구분 |

서비스의 본질은 **"진단·추천이 아닌 정보 제공"** 이며, 이는 단순한 표현 문제가 아니라 **법적 방어선**입니다.

## 2. blah 사이트에서 A.PAGO 를 묘사할 때

blah 는 A.PAGO 의 운영 사이트가 아니라 **회사 소개 사이트**입니다. 그래도 A.PAGO 페이지(`/products/apago`)·홈 섹션·제품 카드·About 등에서 같은 법적 톤을 유지해야 합니다.

### 2.1 절대 쓰지 않는 표현

| 금지 표현 | 사유 |
|---|---|
| AI 도입 병의원 / AI 도입 병원 / 도입 병의원 지도 | 의료법 제27조 — 특정 병원으로 환자 유도 (유인·알선) |
| AI 병원 추천 / 최적 병원 찾기 / AI 가 있는 병원 찾기 | 의료법 제27조 — 환자 유인 |
| 식약처·FDA 인증 (단독 표기) | 한국 의료기기법상 정확한 표기는 "식약처 **허가**". FDA 는 미국 기관이므로 한국 규제 근거로 단정 불가 |
| 최고의 의료 AI / 베스트 AI / 1위 / 가장 정확한 | 의료법 제56조·의료기기법 제24조 — 비교·과장·순위 광고 |
| 100% 정확 / 완벽한 진단 / 정확도 99% | 의료기기법 제24조 — 효능 단정 |
| 병을 발견해드립니다 / AI 가 진단해드려요 | 무면허 의료행위 오인 / 의료행위 유사성 |
| 이 AI 를 쓰면 좋아져요 / 효과를 보장합니다 | 효능 단정 |
| 모든 질환을 발견 (펫 AI) | 수의사법 제32조 — 효능 단정 |
| 추천 동물병원 / 최고의 수의사 | 수의사법 제32조 — 동물진료 광고 |

### 2.2 권장 표현

| 권장 표현 | 효과 |
|---|---|
| 정보를 제공합니다 / 정리해 보여줍니다 | 정보 제공자 정체성 |
| 비교해보세요 / 살펴보세요 / 탐색합니다 | 사용자 주체성 강조 |
| 식약처 허가받은 / 공시된 / 등록된 | 객관적 사실 전달 (실 데이터 매칭 책임 동반) |
| 객관적 / 중립적 / 사실 그대로 | 신뢰성 확보 |
| 분야별 / 카테고리별 / 진료과목별 | 정보 구조화 강조 |
| 진단·추천 대체 아님 / 의료 행위 아님 | 법적 면책 |

### 2.3 핵심 원칙

- **추천·최고·정확** 같은 단어는 피하고, **정보·비교·찾기·안내** 라는 동사 중심으로 작성합니다.
- **"허가"·"공시"·"등록"** 같은 객관성 키워드를 쓰되, 노출되는 데이터가 실제 인허가 정보와 매칭돼야 합니다.
- 카피 한 줄이 광고 규제 위반의 근거가 될 수 있으므로 신중히 작성합니다.

## 3. A.PAGO 의 구조적 안전장치 (blah 카피에 반영해야 할 사실)

A.PAGO 는 의료법·의료기기법 리스크를 **구조적으로 회피**하는 설계로 운영됩니다.
blah 의 소개 카피는 이 사실을 정확히 반영해야 합니다.

### 3.1 의료법 제27조 (유인·알선) 회피 — 매핑 정보 미노출

A.PAGO 는 다음을 **절대로 연결해 노출하지 않습니다.**

- "어느 병원이 어떤 AI 를 쓰는지"
- "이 AI 가 있는 병원 목록"
- "○○ 병원이 □□ AI 를 도입함"

따라서 blah 카피에서도 다음 표현은 사용하지 않습니다.

- ❌ "AI 도입 병의원을 찾는 시민" (audience)
- ❌ "AI 도입 병의원·동물병원을 객관적으로 비교·탐색" (한 줄 정의)
- ❌ "도입 병의원 지도 검색" (기능 소개)

대신 다음과 같이 **두 갈래로 분리**해 묘사합니다.

- ✅ "병의원·동물병원 지도" — 카테고리·위치 기준 정보, 모든 기관 동일 표시
- ✅ "의료 AI 카탈로그" — 식약처 허가 제품을 분야별로 정리
- ✅ "두 정보 사이의 연결은 노출하지 않습니다."

### 3.2 의료법 제56조 (의료광고) 회피 — 병의원 후기 미제공

A.PAGO 는 병의원 후기·평점 기능을 제공하지 않습니다. blah 카피에서도 "병원 후기·리뷰" 를 A.PAGO 의 기능으로 소개하지 않습니다.
(향후 도입 가능한 후기는 "**제품 사용 경험 한정**" 이며, 효능·진단 결과는 후기 본문 차단 대상.)

### 3.3 의료기기법 제24조 (의료기기 광고) — 광고 vs 정보 구분

- 식약처 공공 DB 의 허가사항 그대로 노출 = **광고 아님 (정보 제공)**
- 업체가 비용을 지불해 추가 노출되는 배너·강조 UI = **광고** → 의료기기 광고 사전심의(KMDIA) 필수, "광고" 배지·심의번호·주의사항 표시 의무

blah 사이트에서는 A.PAGO 광고 모델을 직접 다루지 않지만, "광고 받지 않는 객관 정보" 라는 정체성은 A.PAGO 의 차별점이므로 카피에 자연스럽게 드러냅니다.

### 3.4 의료행위 유사성 회피 — 룰베이스 카테고리 안내

A.PAGO 의 "룰 기반 정보 안내(증상→AI 분야 안내)" 는 **직접 제품 매칭 금지** 원칙으로 설계돼 있습니다.

- ❌ "가슴이 아파요" → "○○ AI 추천"
- ✅ "가슴 통증" → "내과 / 이비인후과 등 관련 분야" → 해당 분야 허가 AI 목록 → 사용자가 탐색

blah 카피에서 이 기능을 묘사할 때 "**의료 행위 아님**", "**진단·추천 대체 아님**" 을 함께 표시합니다.

### 3.5 개인정보보호법 — 민감정보 동의 게이트

A.PAGO 는 AI 상담·증상 검색 직전 **1회 동의 게이트**를 노출하며, 입력값은 클라이언트 메모리에만 두고 서버 전송하지 않습니다.

blah 카피에서 "**민감 정보 수집 전 명시적 동의**" 를 약속 항목으로 명시합니다.

### 3.6 위치정보법 — 위치 정보 비저장

위치 정보는 지도 중심 이동 용도로만 사용되며 저장되지 않습니다. blah 카피에서 위치 사용을 언급할 때 이 사실을 함께 표시합니다.

### 3.7 수의사법 — 펫 영역 추가 적용 + 데모 데이터 표기

펫 AI 제품·동물병원 정보에는 수의사법 제32조 가 추가 적용됩니다.
A.PAGO 의 펫 AI 데이터는 현재 가상 데이터이며 `[데모]` 표기로 노출됩니다.

blah 카피에서 펫 영역을 소개할 때:
- "사람·반려동물 듀얼 도메인" 으로 영역만 명시
- 구체적 펫 AI 제품·회사명을 카피에 직접 노출하지 않음
- 실 데이터 연동 전임을 암시할 수 있는 톤 (예: "현재 카탈로그 정비 중") 활용 가능

## 4. 표현 매핑표 — 자주 쓰는 표현 교정

| 잘못된 표현 | 교정 |
|---|---|
| AI 도입 병의원·동물병원을 객관적으로 비교·탐색 | 병의원·동물병원 정보와 식약처 허가 의료 AI 솔루션을 (분리해) 객관적으로 비교·탐색 |
| AI 도입 병의원을 찾는 시민 | 의료 AI 정보가 궁금한 시민 / 의료 AI 에 어떤 제품이 있는지 알고 싶은 사용자 |
| 도입 병의원 지도 검색 | 병의원·동물병원 지도 (모든 기관 동일 표시) |
| 식약처·FDA 인증 의료 AI | 식약처 허가 의료 AI (필요 시 "해외 허가 정보(FDA 등) 참고 표기" 정도로 보조) |
| AI 의료기기 카탈로그 | 허가 의료 AI 카탈로그 / 식약처 허가 의료 AI 카탈로그 |
| 실시간 뉴스 | 분야별 의료 AI 뉴스 (외부 언론 소스, 본 플랫폼이 내용을 보증하지 않음) |
| AI 상담 / AI 가 추천 | 룰 기반 정보 안내 / 카테고리 기반 안내 (의료 행위 아님) |
| 인증 (단독) | 허가 (의료기기법 정확 표기) — "FDA 인증" 처럼 외국 기관 표기와 혼용 금지 |
