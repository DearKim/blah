## 사용 흐름

- 일을 시작할 때 → [milestones-01.md](milestones-01.md) 에서 현재 단계와 다음 체크리스트를 확인합니다.
- 결정이 필요할 때 → [open-questions-02.md](open-questions-02.md) 에 항목으로 등록합니다.
- 결정이 끝나면 → 관련 문서를 갱신하고 open-questions 에서 ✅ 처리하거나 항목을 제거합니다.
