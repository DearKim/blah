# 회사 소개 (`/about`)

## 페이지 목적

홈에서 더 자세히 알고 싶은 사람·파트너 후보·채용 후보가 들어오는 페이지.
"BLAH 가 어떤 사람들이 뭘 위해 만든 회사인지" 를 보다 길게 풀어 둔다.

## 섹션 구성

```
┌─────────────────────────────────────────┐
│ 1. Page Heading                         │
│   - 제목: "BLAH는 어떤 회사인가요"          │
├─────────────────────────────────────────┤
│ 2. 미션 / 한 줄 정의                       │
│   - "고객의 편의를 위한 정보 서비스"          │
├─────────────────────────────────────────┤
│ 3. 가치 (3~4 항목)                        │
│   - 정보 우선 / 편의성 / 신뢰 / 확장성       │
│   - 각 항목당 한 단락                      │
├─────────────────────────────────────────┤
│ 4. 우리가 다루는 영역                       │
│   - 헬스케어 (A.PAGO)                    │
│   - 노동·시간 (TEUM)                     │
│   - "정보가 흩어져 있는 모든 영역"            │
├─────────────────────────────────────────┤
│ 5. 회사 정보 (간단한 표 형식)               │
│   - 법인명 / 대표자 / 설립일 / 주소 / 메일   │
│   - (모두 결정되는 대로 채움)               │
├─────────────────────────────────────────┤
│ 6. CTA                                  │
│   - "함께 일하고 싶다면 / 협업을 제안하려면"   │
│   - 버튼: [문의하기]                      │
└─────────────────────────────────────────┘
```
