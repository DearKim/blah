# 문의 (`/contact`)

## 페이지 목적

채용·파트너십·일반 문의 등을 위한 **연락 진입점**. 정적 사이트라 폼 자체는 두지 않고, 메일·외부 채널 안내로 대체합니다.

```

│ 1. Page Heading                         │
│   - eyebrow: Contact                     │
│   - 제목: "문의"                         │

│            알려주시면 가장 빠르게 응답합니다."  │
├─────────────────────────────────────────┤
│ 2. 대표 이메일 카드                        │
│   - Mail 아이콘 + "대표 이메일" 라벨       │

## 카테고리별 컬러 팔레트

BLAH + 두 제품 색을 자연스럽게 인용한 4종.

| 카드 | 컬러 | 출처 | 아이콘 |
|---|---|---|---|
| 일반 문의 | `#1d9e75` | BLAH brand teal | `MessageSquare` |
| 파트너십 | `#1878CE` | A.PAGO blue | `Handshake` |
| 채용 | `#82C926` | TEUM lime | `Briefcase` |
| 미디어 | `#0f6e56` | BLAH brand-deep | `Newspaper` |

## 카드 구조

```
┌──────────────────────────────┐
│ [accent 헤더 풀블리드]      🔘 │  ← 백색 텍스트 + 아이콘 칩
│ GENERAL                       │     (eyebrow 영문, 0.25em)
│ 일반 문의                      │     (h3, white)
├──────────────────────────────┤
│ [문의]            ← accent 색  │     (font-mono)
│ 제목에 [문의] 를 붙이고...      │     (slate-600)
└──────────────────────────────┘
```

- **헤더 영역** (`px-6 py-5`): 좌측 eyebrow + 라벨, 우측 아이콘 칩 (`bg-white/15 ring-white/25 backdrop-blur-sm`)
- **바디** (`p-6`): subjectTag (accent 색 mono font) + 본문 설명
- **hover**: 카드 `-translate-y-0.5` + `shadow-md`, 아이콘 칩 `scale-105`

```

## 모션·인터랙션

- 카드별 `FadeUp` 50ms 시차 진입
- `prefers-reduced-motion: reduce` 시 자동 비활성

## 반응형

- `grid gap-5 md:grid-cols-2` — 모바일 1열 / 데스크톱 2열
- 헤더 `flex justify-between` + `min-w-0` 텍스트 + `shrink-0` 아이콘 칩 — 좁은 카드에서 깨지지 않음
- 라벨 `truncate` — 모바일 넘침 방지
- 이메일 카드의 메일 주소는 작은 모바일(< 640px)에서 `text-xl` 로 단계화 + `break-all` 로 안전한 줄바꿈

## 향후 옵션

- **외부 폼 임베드** (Tally / Google Forms): 동적 백엔드 없이 폼이 필요해질 때.
- **자동 응답**: 메일 운영자 측에서 설정. 사이트 코드 변경 불필요.
