# 문의 (`/contact`)

## 페이지 목적

채용·파트너십·일반 문의 등을 위한 **연락 진입점**. 정적 사이트라 폼 자체는 두지 않고, 메일·외부 채널 안내로 대체합니다.

## 1차 출시: 단순 안내 페이지

```
┌─────────────────────────────────────────┐
│ 1. Page Heading                         │
│   - 제목: "문의"                         │
│   - 보조: "어떤 이유로 연락을 주시는지       │
│            알려주시면 가장 빠르게 응답합니다." │
├─────────────────────────────────────────┤
│ 2. 문의 채널                             │
│   - 대표 이메일: (미정)                   │
│   - 표기 형태: mailto: 링크 + 클릭 시 메일러 │
├─────────────────────────────────────────┤
│ 3. 어떤 문의를 어떤 채널로                  │
│   - 일반 문의 / 파트너십 / 채용 / 미디어     │
│   - 각각 같은 메일이라도 제목 가이드를 제시    │
├─────────────────────────────────────────┤
│ 4. 회사 위치·운영 시간 (있을 경우)          │
│   - 평일 10:00–18:00 같은 안내            │
└─────────────────────────────────────────┘
```

## 메일 가이드 카피

```
일반 문의 — 제목에 [문의] 를 붙여 주세요.
파트너십  — 제목에 [파트너십], 본문에 회사명·담당자·제안 요지를 적어 주세요.
채용      — 제목에 [채용], 이력서/포트폴리오를 첨부해 주세요.
미디어    — 제목에 [미디어] 를 붙여 주세요.
```

## 향후 옵션

- **외부 폼 임베드** (Tally / Google Forms): 동적 백엔드 없이 폼이 필요해질 때.
- **자동 응답**: 메일 운영자 측에서 설정. 사이트 코드 변경 불필요.

이 페이지는 사이트의 다른 어떤 페이지와도 외부 의존성이 다르지 않으므로(정적), 후일 폼이 추가돼도 임베드 한 줄로 끝납니다.

## SEO

- `<title>`: `문의 | BLAH`
- description: 문의 채널 안내. 키워드: 문의, 파트너십, 채용.
- 검색 노출이 크게 중요하지 않은 페이지 — `<meta name="robots" content="index,follow">` 로 두되 우선순위 낮음.
