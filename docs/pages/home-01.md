# 홈 (`/`)

## 페이지 목적

방문자가 5초 안에 다음 세 가지를 파악하게 한다.

1. BLAH가 어떤 회사인가
2. 어떤 제품이 있는가
3. 더 알아보려면 어디로 가는가

## 섹션 구성

```
┌─────────────────────────────────────────┐
│ Header                                  │
├─────────────────────────────────────────┤
│ 1. Hero                                 │
│   - 회사 한 줄 정의                      │
│   - 보조 설명 1~2 줄                    │
│   - CTA: [제품 보기] [회사 소개]          │
├─────────────────────────────────────────┤
│ 2. 제품 그리드 (현재 2개, 향후 N개)         │
│   ┌────────────┐  ┌────────────┐        │
│   │ A.PAGO     │  │ TEUM       │        │
│   │ 카드        │  │ 카드        │        │
│   └────────────┘  └────────────┘        │
├─────────────────────────────────────────┤
│ 3. 회사가 하는 일 (3 포인트 요약)          │
│   - 정보 우선 / 편의성 / 신뢰              │
├─────────────────────────────────────────┤
│ 4. 마지막 CTA                            │
│   "함께 일하거나, 협업을 제안하고 싶다면"    │
│   → [문의하기] (mailto: 또는 /contact)   │
├─────────────────────────────────────────┤
│ Footer                                  │
└─────────────────────────────────────────┘
```

## 1. Hero 카피

- **헤드라인:** 고객의 편의를 위한 정보 서비스, BLAH
- **서브:** 흩어져 있는 정보를 한곳에서 객관적으로 비교하고 탐색할 수 있도록 만듭니다.
- **CTA:** "제품 보기" (`/products`) — primary / "회사 소개" (`/about`) — outline

## 2. 제품 그리드

- 데이터: [`src/content/products.ts`](../architecture/content-strategy-03.md) 의 `products` 배열을 그대로 매핑.
- 카드 한 장에 노출: 제품명(영문 + 한글) · `tagline` · `summary` 2~3 줄 · 상태 뱃지 · CTA "자세히 보기" → `/products/:slug`
- 그리드: md 이상 2 컬럼, lg 이상 같은 2 컬럼 유지(폭이 충분히 큼). 제품이 3개 이상으로 늘어나면 3 컬럼.

## 3. 회사가 하는 일 (3 포인트)

[../overview/company-01.md](../overview/company-01.md) 의 가치 표를 시각화.

| 아이콘 | 제목 | 본문 |
|---|---|---|
| (info) | 정보 우선 | 광고가 아닌 정보, 추천이 아닌 사실. |
| (grid) | 편의성 | 흩어진 데이터를 한 화면에서 비교·탐색합니다. |
| (shield) | 신뢰 | 출처를 밝히고, 법적·윤리적 가이드라인을 지킵니다. |

## 4. 마지막 CTA

- 텍스트: "함께 만들어 갈 동료, 그리고 협업할 파트너를 찾고 있습니다."
- 버튼: [문의하기] → `/contact`

## SEO

- `<title>`: `BLAH — 고객의 편의를 위한 정보 서비스`
- `<meta name="description">`: 회사 한 줄 정의 + 제품 두 개 언급
- OG 이미지: 회사 워드마크 + 슬로건 (`public/og-image.png`)
