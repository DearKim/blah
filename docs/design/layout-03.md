# 레이아웃 가이드

## 글로벌 레이아웃

모든 페이지는 다음 구조 안에서 렌더링됩니다.

```
┌──────────────────────────────────────────┐
│ Header (sticky, 64px)                    │
│  ├── Logo (BLAH)                         │
│  └── Nav: 제품 | 회사 소개 | 문의          │
├──────────────────────────────────────────┤
│                                          │
│ Main (페이지 콘텐츠)                       │
│   - max-width 1120px, 좌우 패딩 24px     │
│                                          │
├──────────────────────────────────────────┤
│ Footer                                   │
│  ├── 회사 정보 (이름, 사업자번호 등)        │
│  ├── 빠른 링크                           │
│  └── © 2026 BLAH                         │
└──────────────────────────────────────────┘
```

## 컨테이너 규칙

- 본문 컨테이너 `max-width: 1120px` (Tailwind 로는 `max-w-6xl` 근처)
- 섹션 간 세로 여백: 모바일 56px / 데스크톱 96px
- 카드/그리드 간격: 24px

## 반응형 브레이크포인트

Tailwind 기본값을 그대로 사용합니다.

| 이름 | 시작 너비 |
|---|---|
| sm | 640px |
| md | 768px |
| lg | 1024px |
| xl | 1280px |

레이아웃 전환 기준점은 **md (768px)** 와 **lg (1024px)** 두 곳입니다.

- md 미만: 헤더 네비를 햄버거 메뉴로 (단일 컬럼)
- md 이상: 인라인 네비, 섹션은 2~3 컬럼 그리드 가능
- lg 이상: 본문 max-width 컨테이너로 좌우 여백

## 페이지 구성 원칙

- 한 페이지에 **섹션 5개 이내.** 더 들어가면 정보가 흩어진다.
- 모든 페이지는 첫 화면(viewport 1개) 안에서 "여기가 뭐 하는 페이지인지" 파악 가능해야 한다.
- 페이지 하단에는 다음 행동(CTA) 또는 다음 페이지 링크가 있다.

## 헤더

- 배경 흰색, 하단 1px 라인 (`border.default`)
- 좌측: 로고만 (텍스트 워드마크 → 추후 SVG 로 교체)
- 우측: 네비 항목 3개 + (선택) 우측 끝에 강조 CTA 1개 (예: "문의")
- 스크롤 시 그림자 약하게 (`shadow-sm`)
