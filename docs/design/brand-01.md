# 브랜드 가이드

## 회사명

- 영문: **BLAH** (대문자가 기본)
- 한글: **블라**
- 본문 흐름 안에서 자연스럽게 "BLAH" 또는 "블라"로 표기. 두 표기가 동시에 노출되는 곳(예: 푸터)에서는 한글 → 영문 순서.

## 브랜드 컨셉 — Echo Wave

> "어쩌구저쩌구의 블라블라" 에서 출발한, 정보를 전하는 회사.

BLAH의 시각 정체성은 **5개 막대로 구성된 사운드 파장**과 **BLAH 워드마크**의 결합입니다.
가운데가 가장 높고 좌우로 줄어드는 막대 패턴(▁▃▆▃▁)은 다음을 상징합니다.

- **사운드 웨이브** — 정보가 소리처럼 사용자에게 전달되는 모습
- **중앙 정점 구조** — 본질에서 출발해 좌우로 퍼지는 정보의 흐름
- **리듬과 균형** — 일방적 전달이 아닌, 대화적 교환
- **BLAH 워드마크** — 친근하고 거리낌 없는 발화

핵심 키워드: **신뢰 · 전달 · 울림 · 명료함**

로고·아이콘 자산의 파일별 사용 가이드는 [brand-assets-04.md](brand-assets-04.md) 에 있습니다.

## 보이스 (사이트 톤)

- **간결하다.** 한 문장에 한 메시지.
- **신뢰감 있다.** 추측·과장 없이 사실 위주.
- **편안하다.** 전문 용어 남발 금지. 모르는 사람이 와도 한 번에 읽힌다.
- **비교·정보 중심.** 우리 회사를 띄우기보다, "방문자가 알아야 할 것" 을 먼저 둔다.

좋은 예 / 나쁜 예:

| 상황 | 좋은 예 | 나쁜 예 |
|---|---|---|
| 회사 소개 | "고객의 편의를 위한 정보 서비스를 만듭니다." | "혁신적이고 차별화된 서비스로 미래를 선도합니다." |
| 제품 소개 | "10분·30분·4시간 단위 일거리를 한곳에서 봅니다." | "단연 최고의 긱워크 플랫폼!" |
| 푸터 | "© 2026 블라. All rights reserved." | "감사합니다 ♥" |

## 금칙·주의 표현

### 공통 (사이트 전체)

- "최고", "1위", "유일한", "완벽한" — 근거 없이 쓰지 않음.
- "추천" — 의료·노동 영역에서 함부로 쓰면 법적 이슈가 됨. "안내", "정보 제공" 으로 표현.
- 이모지 — 본문에서 사용하지 않음. 카피 톤이 가벼워진다.

### 의료(A.PAGO 영역) 전용 — 의료법·의료기기법·수의사법

A.PAGO 를 소개·연결하는 모든 카피(홈 섹션·제품 카드·`/products/apago`·About 본문)에 다음을 추가로 적용합니다.

- "**AI 도입 병의원**", "**도입 병원**", "**AI 가 있는 병원 찾기**" — 의료법 제27조(환자 유인·알선) 위반 소지. **사용 금지**.
- "**식약처·FDA 인증**" — 한국 의료기기법 정확 표기는 "**식약처 허가**". FDA 단독 표기·혼용은 사용 금지.
- "**가장 정확한**", "**100% 진단**", "**정확도 99%**" — 효능 단정. 사용 금지.
- "**AI 가 진단해드려요**", "**병을 발견해드립니다**" — 무면허 의료행위 오인. 사용 금지.
- "**최적 병원 찾기**", "**○○ 병원 추천**" — 환자 유인. 사용 금지.
- 펫 영역에서 "**모든 질환 발견**", "**최고의 동물병원**" — 수의사법 제32조 위반. 사용 금지.

권장 대체:

- "허가받은", "공시된", "등록된" — 객관적 사실 (단, 데이터 매칭 책임).
- "정보를 제공합니다", "비교해보세요", "탐색합니다", "안내합니다".
- "의료 행위 아님", "진단·추천 대체 아님" 을 룰 기반 안내·증상 검색 기능 설명에 함께 표기.

## 타이포그래피

- 본문: **SUIT Variable** (한국어 가변 폰트, 100~900 가중치). 글자 모서리가 살짝 둥글고 자간이 여유로워 정보 사이트의 신뢰감을 유지하면서도 부드러운 인상을 준다.
- 폴백: Pretendard → 시스템 산세리프
- 워드마크 (로고 SVG 내부): **Inter Medium (500)**, 인쇄 시에는 outline 변환
- 본문 16px, 행간 약 1.6
- 헤딩은 단계별 시각 차이를 명확히 (h1 ≥ 36px, h2 ≥ 28px, h3 ≥ 22px)

폰트 체인:
```css
"SUIT Variable", "Pretendard Variable", "Pretendard", ui-sans-serif, system-ui,
  -apple-system, "Segoe UI", "Apple SD Gothic Neo", "Noto Sans KR", sans-serif
```

SUIT 는 [index.html](../../index.html) 의 `<link>` 로 jsdelivr CDN 에서 변동축 woff2 1개 파일로 로드됩니다 (가중치 전체를 단일 파일로 커버).
