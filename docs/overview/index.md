# overview — 회사·제품 개요

회사가 무엇이고, 어떤 제품을 안내하는 사이트인지에 대한 큰 그림을 모아두는 폴더입니다.

## 무엇이 들어가나

- BLAH 회사의 정체성, 미션, 가치
- 사이트가 안내하는 제품 포트폴리오의 **한눈에 보기**
- 새 제품이 추가되거나 회사 정보가 바뀌면 이 폴더의 문서를 먼저 갱신합니다.

여기서는 **개요만** 다룹니다. 사이트에 실제로 노출되는 카피 시안은 [../content/](../content/), 페이지별 화면 구성은 [../pages/](../pages/) 에 있습니다.

## 새 문서를 추가할 때

다음 중 하나에 해당하면 이 폴더에 추가합니다.

- 회사 차원의 정체성·가치·역사를 다루는 새 주제
- 제품 포트폴리오 전반에 대한 설명 (단일 제품의 카피가 아니라 전체 비교)
- 회사가 다루는 영역(도메인) 의 큰 분류 변화

이 폴더에 새 문서를 만들 때:

1. 다음 번호(`03`, `04`, …) 로 파일명을 짓습니다.
2. 위 표에 한 줄을 추가합니다.
3. 단일 제품의 본문 카피는 [../content/](../content/) 로 가야 합니다.
